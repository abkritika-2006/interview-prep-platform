# Interview Prep Platform
Full-stack interview preparation platform built with Java, Spring Boot, PostgreSQL, and React. Features DSA progress tracking, analytics dashboard, revision scheduling, and authentication.

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication

### Database
- PostgreSQL

### Frontend
- React
- HTML
- CSS

### Deployment
- Vercel
- Render

## Features

### Phase 1
- User Registration
- User Login
- JWT Authentication

### Phase 2
- Add Solved Questions
- Edit Questions
- Delete Questions
- View Progress

### Phase 3
- Analytics Dashboard
- Topic-wise Statistics
- Difficulty-wise Statistics

### Phase 4
- Revision Scheduler
- Reminder System

### Future Scope
- AI Progress Analysis
- Mock Interview Generator
